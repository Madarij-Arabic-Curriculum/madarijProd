# madarijProd

## Curriculum demo

The vault currently uses mock curriculum data in `script.js`. Materials use
placeholder download, view, and print actions while the curriculum structure
is being designed. Google Sheets-to-JSON integration can be added later.

The dictionary page currently uses four mock entries in `script.js`. Nouns
show singular, dual, and plural forms. The verb entry shows its Baab with
past, present, masdar, derived forms, and a complete 14-form conjugation
table. The alphabetical search and entry layout are ready to be connected to
a JSON dictionary when the data source is available.
